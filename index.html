記法とレイアウトのガイド

--- の独立行でスライドを区切ります。# はタイトル、## は構成要素、- は項目、**強調**、> は結論です。

<!-- layout: message -->：大きなキーメッセージ。compare：見出し2つで左右比較。pillars：見出し3つで3本柱。process：見出し3〜5つを順序付き工程に変換（段落は説明、箇条書きは成果物）。未指定時は見出し2つ→比較、3つ→3本柱、それ以外→メッセージ。

matrix：見出し4つを左上・右上・左下・右下に配置。<!-- x-axis: 工数 / 小 / 大 --> と <!-- y-axis: 効果 / 小 / 大 --> が必須。横軸は左→右、縦軸は下→上に増加します。象限見出し12字、項目2件・各20字、軸名16字、両端ラベル各10字を推奨。軸内の / は区切り専用です。

problem-solution：見出し2〜3つを行にし、各行に - 課題:、- 原因:、- 対策: を1件ずつ記述します（全角：も可）。原因は仮説として表示します。行見出し12字、各セル40字を推奨。不足・重複・未知の項目では入力確認表示になります。

推奨：タイトル36字、結論60字、見出し16字、本文・項目各50字、各列3項目まで。processは見出し12字、説明40字、成果物1項目30字を推奨（5工程では合計60字/工程）。構造不正時は入力確認表示になります。長い内容はスライドを分割してください。HTML・リンク・画像は実行せず文字として表示します。全画面では ← → / Space、Home / End、Esc を使用できます。

第2群：説明と意思決定

logic-tree：<!-- root: 論点 -->、見出し2〜3個、各子1〜2件。ルートを含め10ノードまで。pyramid：> を結論、見出し2〜3個を根拠にします。

roadmap：先頭列「施策」の表で、期間3〜6列・施策3〜5行。「実施」を連続させ、「-」で非実施を明示。evaluation：先頭列「判断基準」、案2〜4列・基準3〜5行。各セルは「○ 根拠」など、または「未評価」。<!-- recommend: 案B --> で推奨案を指定できます。表は外側の | と --- の区切り行が必須。セル内の | は \| と記述します。

kpi：<!-- period: 対象期間 --> と指標3〜4個。各見出しの下に - actual:、- target:、- unit: を指定。数値はカンマや指数を含まない十進数。recommendation：> を提言とし、「判断理由」に2〜3項目、「次のアクション」に - action:、- owner:、- due: を指定します。

新規6種は必ず <!-- layout: ID --> で明示指定してください。初期サンプルには全21種を含みます。要素数や必須入力の不備は原文付きの入力確認表示になります。

第3群：数値と実行管理

bar は「項目 / 値」、line は「期間 / 値」、waterfall は「区分 / 項目 / 値」の表と <!-- unit: 単位 -->。棒は3〜7件、折れ線は4〜8時点（欠測は「欠測」）、増減は start → delta（2〜5件）→ end。数値は有限の十進数で、合計不整合は図にしません。

composition は「区分 / 割合」の表で3〜5件、合計100%（±0.1ポイント）。%記号は付けません。funnel は「段階 / 件数」の表で3〜5段階、単位と <!-- cohort: 期間と母集団 --> が必須。非負整数の件数を減少順で記述します。

cycle は <!-- center: 循環の目的 --> と見出し4個（左上→右上→右下→左下）。value-chain は「主活動」「支援活動」の見出しの下に「- 活動名: 説明」を記述し、主活動3〜5件・支援1〜2件。

swimlane は先頭列「担当」の表で2〜3主体×3〜5工程。各列の主担当を1つとし、非担当は「-」。risk-register は「リスク / 重大度 / 対応 / 責任者」の表で3〜4件、重大度は高/中/低。判定基準を段落で添えます。新しい9種もレイアウトは明示指定し、初期サンプルには全21種を含みます。
