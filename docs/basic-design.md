# 基本デザイン

共通フッターと色の設定を提供する。Issue #33で追加したロゴ機能は、ロゴが原稿QRに含まれず別途受け渡しが必要であることを踏まえたユーザーの廃止指示により削除した。公開済み0.0.2のリリース資産は変更しない。

## 操作

「基本デザイン」で全スライド共通の左下文字列とコーポレートカラーを設定する。

- 左下文字列：既定は空欄。改行・制御文字なし、Unicodeで80文字まで。40文字程度を推奨。長い内容は適用後のはみ出し警告も確認する。
- 色：既定#CC0033。色選択または#RRGGBBで入力する。塗り色は保持し、文字・罫線には視認性を補う濃い補助色を使い、薄い背景と塗り上の白黒文字を導出する。白背景、アプリ操作UIの色は変更しない。

設定画面内でプレビューし、「全スライドに適用」で現在の原稿へ適用する。原稿は変更しない。キャンセルは既存設定を維持。「初期値に戻す」も適用するまでプレビューのみ。画像選択やロゴ表示のための専用余白・枠はない。スライドの型名・固定SlideSeed表記も表示しない。ページ番号、アプリのライセンス表示は維持する。

## 保存・再利用

「表示中の設定を保存」でSlideSeed-theme.jsonを保存できる。未適用のプレビュー設定も保存対象。

```
{"format":"SlideSeedTheme","version":1,"theme":{"color":"#CC0033","footer":"会社名"}}
```

新しい設定ファイルにロゴは含めない。旧形式のlogo:nullは互換入力として受け付けて破棄する。ロゴデータを持つ旧ファイルは「ロゴ機能は廃止」と明示して拒否し、現在の設定を保持する。画像データを読み込んだりデコードしたりしない。

未知の形式・バージョン・フィールド、不正色・文字列は拒否する。設定読込中は適用・保存を無効にし、閉じる・新しい読込・編集で古い非同期結果を無効にする。原稿のMarkdown・QRにはデザイン設定を含めない。設定ファイルは別管理で、自動永続保存はしない。

別のMarkdownを開いても、そのアプリで適用済みの設定は維持する。ページを閉じる前に必要な原稿と設定をそれぞれ保存する。再起動は既定の設定から始まる。
