# 基本デザインと一括サンプル置換の廃止

Issue #32 / #33。PR #31の空原稿・選択テンプレート機能への追加変更。

## 一括置換廃止

「全21種のサンプルで置換」とハンドラーを撤去する。同じ操作を別名で残さない。全21種のデータとsamples/demo.mdは維持し、選択した型を現在のスライドの後へ追加できる。ブラウザ検証ページのサンプルは検証ページ自体から投入し、製品に検証用の置換ボタンを残さない。

## 基本デザイン

ツールバーの「基本デザイン」で全スライド共通の以下を設定する。

- 左下の文字列：既定は空。改行・制御文字なし、Unicodeの文字数で80文字まで。40文字程度を推奨。長い内容は無断省略せず、適用後のはみ出しチェックでも確認する。
- コーポレートカラー：既定#CC0033。色選択と#RRGGBB入力に対応。白背景やアプリの操作UIは変更せず、スライド内のアクセントと薄い派生背景に適用する。塗り色は保持し、淡い色には文字・線の濃い補助色を用いる。塗り上の文字は白／黒を選択する。
- 右上ロゴ：任意。指定しなければ枠・未設定表示も出さない。タイトルとの専用余白を設け、縦横比を保つ。変更・取り外しが可能。

固定のSlideSeed表記と左上の型名はスライドに描かない。ページ番号、プレビュー外のレイアウト識別、アプリ名とライセンス表示は維持する。

設定画面内の変更はプレビュー用。「全スライドに適用」で現在のプレビュー・発表・印刷に適用し、原稿は変更しない。キャンセルで既存設定を保持。「初期値に戻す」もプレビュー用で、適用しない限り現在の設定は変わらない。画像／設定の読込中は適用と保存を無効にし、閉じる・新しい読込・編集で古い非同期結果を無効化する。

## ロゴの取り込みと上限

端末内の静的PNGまたはJPEG。拡張子や申告MIMEを信用せず、シグネチャ、PNGチャンク／JPEGフレーム、寸法を確認する。2MiB以下、各辺8192px以下、16,777,216画素以下をデコード前に検査。SVG、HTML、アニメーションPNGは対象外。

ブラウザ標準createImageBitmapでデコードし、ヘッダーの寸法と確認したうえで最大640×192pxへ縮小（小さい画像は拡大しない）、PNGへ再描画する。PNGのデータURLが512Ki文字を超える場合はさらに半分に縮小して上限を検証する。壊れた画像や取り込み失敗時は現在のロゴを保持し、理由を表示する。JPEGの回転情報による縦横の入れ替えも考慮する。

スライドには、デコード済みの縮小画像をCanvasへ同期描画する。印刷用スライドにもその場で描けるため、印刷直前の非同期画像取得・読込に依存しない。外部URLもローカルファイルのパスも参照せず、CSPのimg-src 'none'／connect-src 'none'を維持する。Markdown中の自由なHTML・画像を解禁しない。

画像は会社ロゴに限定する。自由配置や本文の画像挿入は対象外。URLからの取り込みは#34の検討項目として未実装で、外部通信禁止の例外は導入しない。

## 設定の保存・再利用

「表示中の設定を保存」でSlideSeed-theme.jsonを書き出す。未適用のプレビュー設定も保存対象であることをボタン名で示す。設定ファイルは以下の形でロゴのPNGデータを内蔵する。

```
{"format":"SlideSeedTheme","version":1,"theme":{"color":"#CC0033","footer":"会社名","logo":null}}
```

ロゴありの場合はlogoをデータURLだけを持つオブジェクトにする。ファイルは600,000バイト／文字以下、ロゴのデータURLは524,288文字以下。未知の形式・バージョン・フィールド、不正色や文字列・ロゴは拒否し、検証／画像デコード完了後にプレビューへ反映する。

設定と原稿は別管理。Markdown保存・QRは原稿だけを運ぶ。別端末で同じデザインを使う場合は設定ファイルも渡して読み込む。ファイルから別のMarkdownを開いても、適用済みの会社設定はそのアプリ内で継続する。ブラウザへの自動永続保存はしないので、閉じる前に必要な設定と原稿をそれぞれ保存する。再起動は既定のデザインから始まる。
