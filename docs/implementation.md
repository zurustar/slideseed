## 起動・配布

`index.html` だけを配布し、Chrome / Edgeで直接開く。インストール、サーバー、ビルド、ネット接続は不要。サンプル、CSS、JavaScriptはすべて内蔵。フォントは端末のMeiryo UI → Meiryo → Yu Gothic → sans-serif。フォントのダウンロードは行わない。

## 実装済み

- 左Markdownエディタ、右ライブプレビュー、スライド選択・前後移動、ページ番号。
- `message`：結論を大きく表示し、補足を下段に配置。
- `compare`：左右2列、右列をアクセントで強調。
- `pillars`：番号付き3列、見出し・説明・根拠の階層化。
- `process`：順序付きの3〜5工程と成果物。
- `matrix`：軸名・両端が明示された2×2分類。
- `problem-solution`：論点ごとの課題・原因仮説・対策の対応表。
- 白、#CC0033、16:9（1280×720）、共通余白・タイポグラフィ。
- 日本語の禁則処理（`line-break: strict`）、長い英数字の折り返し。
- 全スライドの実寸DOMを測定し、はみ出しを警告。入力内容は保持し、フォントは縮小しない。プレビュー全体のみ画面に合わせて拡縮する。
- 全画面発表、←→ / 上下 / Space / PageUp・Down / Home・End / Esc。API失敗時はウィンドウ内の発表表示。
- UTF-8 Markdown読込・保存、サンプルへの置換、記法ヘルプ。
- 全スライドの印刷用DOMと16:9の印刷ページ（PDF保存はブラウザ印刷ダイアログで指定）。
- HTMLはテキストとして描画。DOM生成はcreateElement/textContent/text nodeのみ。CSPで通信・画像・外部リソースを禁止。永続保存はしない。

## 確定した入力仕様

- `# タイトル`：各スライド1つ。複数の場合は追加分を本文として保持し警告。欠落時は「無題のスライド」と警告。
- `## 見出し`：構成要素の開始。以降の通常行と項目をその要素に所属させる。
- `- 項目`：箇条書き。通常の非空行は段落。空行は無視。
- `**文字列**`：単一行の強調。入れ子の強調やMarkdown完全互換は対象外。
- `> 結論`：スライド共通の結論。複数行は空白で連結し、messageでは主表示、比較・柱では下段に配置。
- `---`：前後の空白を許す独立行で分割。空スライドも保持して修正を促す。
- `<!-- layout: ID -->`：独立行で指定。複数指定は最後を採用し警告。未対応IDはmessageへフォールバックし警告。
- 未指定時：見出し2個→compare、3個→pillars、それ以外→message。常に同じ結果。
- compareは見出し2個、pillarsは3個を想定。不一致は警告し、追加要素もDOMに保持（はみ出し時は修正が必要）。最初の見出しより前の本文も表示する。
- 推奨：タイトル36字、結論60字、見出し16字、本文・項目各50字、各列3項目まで。超過時は警告。文字数はJavaScript文字列の長さに基づく目安。
- HTML、画像、リンク、コードブロック、表などの未対応構文は文字として表示し、実行・取得しない。

## Issue #4：matrix の追加

- 対応レイアウトは5種。`<!-- layout: matrix -->` を明示し、自動選択は変更しない。
