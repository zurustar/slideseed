# 第3群：数値と実行管理の9パターン

Issue #12〜#20を実装。第1群までの6種、第2群6種と合わせ、対応パターンは21種。要件の正本は `requirements.md` のまま変更しない。配布物は単一の `index.html`、外部通信・CDN・外部フォント・実行時ライブラリ依存・永続保存は追加しない。

## 共通入力とエラー処理

新規9種は `<!-- layout: ID -->` で明示指定。既存の未指定時選択（見出し2個→compare、3個→pillars、その他→message）は変えない。追加コメントは当該layoutだけで解釈する。外側の `|`、ヘッダー、各列 `---` の区切り行を持つ共通テーブル記法を再利用。セル内の `|` は `\|`、バックスラッシュは `\\` と記述する。

構造不正・必須値欠落・不正数値・合計不整合では図を作らず、警告とスクロール可能な原文確認表示に切り替える。推奨文字量の超過や明示的な未確定状態は警告する。内容の削除・要約・並べ替え、無制限の文字サイズ縮小はしない。元のMarkdownは読込・編集・保存で保持する。

文字量は各部品の目安であり、長いタイトル・本文・結論をすべて上限まで同時に使える保証ではない。実寸DOM測定のはみ出し警告も併用し、必要ならスライドを分割する。すべての入力は文字として扱い、任意HTMLやJavaScriptを実行しない。

## 数値と計算の扱い

- 数値は有限の十進整数/小数（先頭の+/-は可）。指数、カンマ、単位付き、NaN、Infinity、16進は受け付けない。`line` の `欠測` だけを専用のnullとして保持する。
- 変換後に0へアンダーフローする非ゼロ値は、ゼロと偽らずエラーにする。funnelはNumber.isSafeIntegerかつ0以上（最大9007199254740991）を必須にし、不正な整数精度で率を計算しない。
- 表示値は入力表記を保持し、数量ラベルは勝手に丸めない。表示12字を推奨。15桁を超える有効桁は、図形に浮動小数点近似があることを警告する。桁差で図形が見えにくい場合も警告し、最小長への拡大はしない。
- 軸はゼロを含み、最大絶対値で正規化してから座標を計算する。大きな正負値の差で計算が無限大にならないようにする。軸目盛だけを有効4桁に丸め、データラベルは保持する。
- 全ゼロのbar/lineは軸範囲0〜1を表示上の規約とし、数量はすべて0のまま。軸上限1が表示用であると警告・注記する。funnelの全ゼロは幅0、転換率は算出不可。
- waterfallとcompositionの合計は補償和（Neumaier法）で計算する。waterfallの終点比較は「絶対誤差1e-12以下、または相対誤差1e-10以下」を許容。微小な単位で許容幅が大きくなる場合は、利用者が単位を見直す。累積値が非有限なら描画しない。
- compositionは合計100%とのずれ±0.1ポイントを許容（境界の浮動小数点差は1e-9ポイントまで）。各幅は入力値の%をそのまま使い、100%へ再配分しない。丸め差で帯の端は100%の目印からごくわずかにずれることがあり、合計を小数第10位までに丸めて注記する（各入力値と幅は未補正）。
- funnelの転換率だけは前段比を小数第1位に丸める。全体比と混同せず、母数0は除算しない。傾向の自動要約・因果推定・予測・良否判定は追加していない。

チャートの設計座標は1280×720のスライド、本文幅1152。折れ線とwaterfallの描画領域は1032×174、外側に目盛・直接ラベル・期間名の余白を確保する。プレビューではスライド全体だけを拡縮し、印刷でも同じ座標を用いる。SVGや外部チャートライブラリは使わず、アプリ所有のHTML要素とCSSで描画する。

1. index.htmlをローカルで開き、ネットワーク切断下で全21種の編集・切り替え・保存を確認。
2. barの正負とゼロ基準、lineの欠測前後の非接続、waterfallの符号・浮動棒・合計、compositionの小区分/0%の外側ラベル、funnelの前段比と0分母を確認。

4. 各要素数の上限、長い日本語ラベル、長い数値、長文タイトル・結論の併用で、警告と入力保持を確認。カード・線・数字の衝突、意図しない切れがないこと。
5. Chrome/EdgeのWindows Meiryo UI、macOS代替フォント、縮小プレビュー・全画面・キー操作を確認。
6. PDFで21ページ、16:9、表・罫線・バー・ラベルが欠けないこと。モノクロでも番号・符号・文字・罫線で読み取れること。
